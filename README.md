# MeowLauncher Beta

通用版 Tauri 源码保留分支，基于此前已公开的 0.7.1 脱敏快照。作者：zkonikishi。

官网与项目主页：https://github.com/zkonikishi/MeowLauncher

本分支保留 Rust + Tauri 2 实现，不是 Electron 主线。通用版由服主自行配置服务地址；自定义版 MeowLauncher Max 维护在独立私有仓库，官网为 https://mrad.meowopia.com。

本地完整源码已独立备份，不得因新版框架开发删除。历史版本不改写；今后开发命名采用 26.3-snapshot-1 → 26.3-pre-1 → 26.3-rc-1 → 26.3。

该历史快照不代表新版本已完成，游戏、多开及生产部署未在此次备份中验收，多开仍暂停。使用范围及权利声明见 NOTICE.txt。
