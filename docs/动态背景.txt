Create a production background asset for a Chinese DNF level-86 era fantasy game launcher. Wide landscape 16:9, 1920x1080 or larger. 当前动态由 CSS 缓慢推近与 Canvas 光尘／细小落叶组成，不是生成的视频。
Canvas 限速为 24 FPS；页面隐藏时停止请求动画帧。右上角可暂停，系统减少动态效果偏好会默认关闭。
动态不包含声音。切换登录／大厅不会重建动画。
要替换为视频，将本地 MP4 或 WebM 放入 ui/assets，然后在 scene-config.mjs 中填写相对路径并重新构建。
视频强制静音、循环播放，加载或播放失败时回退到静态原画及现有粒子动效。
登录和大厅的官方米歇尔背景、活动宣传图已停止使用，复古版保持原花枝底图。
